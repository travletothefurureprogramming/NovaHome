# Nova Home - Personal Portofolio

NovaHome is a minimal, ultra-fast, and distraction-free personal portfolio website built with pure HTML5 and modern CSS. Designed with a dark slate layout, clean typography, and responsive component cards.

---

## Features

- **Minimalist Dark Theme**: Sleek neutral color palette (`#0f1115`) optimized for readability.
- **Pure CSS (No Frameworks)**: Zero external dependencies, fast loading times, and full custom control.
- **Responsive Layout**: Designed with a centered max-width container (`680px`) that adapts seamlessly to mobile and desktop screens.
- **Skill Pill Badges**: Clean inline badges showcasing core competencies.
- **Project Cards**: Interactive hover states highlighting open-source repositories and hardware/software builds.

---

## Built With

- **HTML5**: Semantic markup layout.
- **CSS3**: Custom CSS variables, Flexbox layouts and modern resets
